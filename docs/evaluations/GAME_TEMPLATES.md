# Game templates and samples

Samples live in `samples/`. Each one is a `Scripts/` folder plus a README, and is checked by a test that
compiles every script (Luau) or reads it (Python).

| Sample | What it shows |
|---|---|
| `python_game` | A Python script that moves a crate and counts bumps |
| `obby` | Checkpoints and a kill brick (Luau) |
| `tycoon` | A dropper, a collector and a money counter (Luau) |
| `platformer` | Jump pads and coins (Luau) |
| `rhythm` | Notes timed to a beat (Luau) |
| `cross_language` | A Luau script and a Python script in one game |

The scenes and art are not included; add parts named as the README says, or import a Roblox place.
